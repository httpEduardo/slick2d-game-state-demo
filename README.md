# Slick2D Game State Demo

![Java](https://img.shields.io/badge/Java-Slick2D-ED8B00?logo=openjdk&logoColor=white)

A small Java desktop game example using Slick2D's state-based API. The `Game` class initializes separate menu and play states and opens a `640 × 360` window.

## Project status

The source requires the Slick2D library, but this repository does not include a build configuration. Add the library to your Java classpath before compiling `Game.java`.
